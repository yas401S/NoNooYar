# نونویار – برنامه آموزشی مهدکودک (۴ سال)

این نسخه یک نمونه اولیه آفلاین و قابل اجراست. هیچ API پولی، حساب کاربری یا اینترنتی لازم ندارد.

## امکانات فعلی
- حروف الفبای فارسی با کارت‌های بزرگ
- شمارش ۱ تا ۱۰
- رنگ‌ها و شکل‌ها
- حیوانات و نام/صدای گفتاری با قابلیت گفتار دستگاه
- بازی حافظه ساده
- نقاشی آزاد
- ذخیره ستاره‌های کودک روی دستگاه
- قفل والدین ساده برای بخش تنظیمات (در نسخه بعدی تقویت می‌شود)

## ساخت APK
1. این پوشه را در یک مخزن GitHub جدید با نام `NoNooYar` قرار دهید.
2. از تب Actions، گردش‌کار `Build Android APK` را اجرا کنید.
3. فایل APK از بخش Artifacts دانلود می‌شود.

نیازمندی ساخت: Android Gradle Plugin 8.6.1 و JDK 17.
